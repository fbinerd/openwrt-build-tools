# AI Memory

This directory is the shared working notebook for agents.

Use it to keep a short, current record of:

- what is being worked on
- what was learned
- what remains blocked
- which files or commands matter next

Suggested flow:

1. Read `active.md` before making changes.
2. Add a brief note after meaningful progress.
3. Move stale notes to `archive/` once the topic is done.

Keep entries concise and factual.
