# Container Layout

This directory groups container roles by purpose.

- `openwrt-builder/`: OpenWrt build image used by `start.sh docker`
- `firmware-extract/`: firmware extraction and reconstruction work
- `serial-lab/`: UART / TTL recovery work
- `tftp-lab/`: TFTP recovery work

The implementation code and live workspaces still live under `tools/` and the root scripts.
